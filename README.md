A villain monologue of exactly 100 words: a dark lord six hundred years into the job, exhausted by thrones, prophecies, minion grievances and heroes who never hurry. Weary, funny, and still faintly menacing — he would conquer you, but first, a nap.

Running `main.py` prints the monologue and writes it to `entry.txt` in the output directory.

## Run it

```sh
python3 main.py
```
